# Globetrotter Gateway — Master Codebase Architecture & File Index Map

This document provides an exhaustive, line-by-line architectural map of all core source files across the Globetrotter Gateway ecosystem.

## 1. System Topology Overview

- **Frontend**: Single Page Application built on React 18, Vite v8, Tailwind CSS, and Framer Motion spring physics.
- **Edge Layer**: Cloudflare Pages with Global CDN, TLS 1.3, Strict-Transport-Security, and Edge Worker (`_worker.js`) proxying Gemini 3.8 Flash.
- **Backend**: Spring Boot 3.3.0 on Java 21 Virtual Threads (Project Loom), Caffeine in-memory caching, HikariCP connection pooling, and H2/MySQL persistence.
- **AI Engine**: Google AI Studio Free-Tier Sovereign Multi-Model Router with sliding-window predictive rate-limiting and 60-second cool-offs.
