### Sub-topic: The 7 Core UX Psychology Laws & Cognitive Conversion (Reel 34 & @skill:ui-ux-pro-max)

| Psychology Law / Heuristic | Conversion Standard & Human-Centered Design Rule | Verification & Enforcement |
| :--- | :--- | :--- |
| **1. Jakob's Law** | Users spend most time on other websites; conform to established navigation, search, and checkout patterns. | Top-fixed header, standardized pass drawer, universal search. |
| **2. Fitts's Law** | Touch targets must be $\ge 44 \times 44\text{px}$ with $\ge 8\text{px}$ spacing; critical actions placed in thumb-reach zone. | `CodeTurtle A11Y-FITTS-001`, mobile navigation docks. |
| **3. Hick's Law** | Minimize cognitive decision time by curating complex choices into structured 3-tier models. | 3-tier pass models (Single-Day, Heritage 3-Day, Grand Circuit). |
| **4. Miller's Law** | Working memory holds $7 \pm 2$ chunks; structure destinations into daily bundles of 4–6 stops. | Regional corridor groupings, avoid flat 59-district dropdowns. |
| **5. Law of Proximity** | Related UI elements visually grouped inside dedicated cards with uniform padding ($16$–$24\text{px}$). | Circuit cards, destination price-and-action grouping. |
| **6. Aesthetic-Usability Effect** | Polished visual aesthetics (Cinzel, Plus Jakarta Sans, 60-30-10 palette) increase perceived credibility and trust. | $10,000 Web Stack, zero AI slop, anti-template styling. |
| **7. Zeigarnik Effect** | People remember incomplete tasks; multi-step workflows must include animated progress steppers. | PassIssuanceModal, 4-step tour customization progress bar. |
